# PocketVaidya — v1 clickable mockup

A private "doctor in your phone": screens for early warning signs using the phone's camera, microphone and wearable data, explains results in plain language (English / हिंदी), and connects to AI assistants through MCP. Nothing leaves the phone.

**This is a frontend-only prototype.** All numbers are mock data; scans are animated simulations. *Screening, not diagnosis.*

wHACKiest 2026 · Team Ctrl+Alt+Defeat

## Run

```bash
npm install
npm run dev
```

Stack: Vite · React · TypeScript · Tailwind · React Router · Framer Motion · Recharts · lucide-react.
See `docs/STATUS.md` for the screen list.
